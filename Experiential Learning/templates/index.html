Computer Science Theory & Algorithm Notes

1. Expression Tree Definition

An Expression Tree is a specific binary tree representation of an arithmetic expression. The leaves of the tree are operands (numbers), while the internal nodes are operators (+, -, *, /, etc.). Subtrees correspond to sub-expressions.

2. Operator Precedence Hierarchy

Evaluated according to standard algebraic hierarchy:
• () Parentheses (Highest)
• ** Exponentiation (Right-Associative)
• Unary +, - (Right-Associative)
• *, /, //, % (Left-Associative)
• Binary +, - (Left-Associative)

3. Tree Traversals

• Pre-order (Prefix): Process root before subtrees. Produces Polish notation.
• In-order (Infix): Process left subtree, root, then right subtree. Produces standard arithmetic notation.
• Post-order (Postfix): Process subtrees before root. Used for bottom-up numerical evaluation without parentheses!

4. Pure Python Security

The backend deliberately avoids eval(), exec(), and ast.literal_eval(). All expressions are parsed into an Abstract Syntax Tree (AST) using a custom lexer and recursive-descent grammar, preventing arbitrary code execution.
